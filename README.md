A tiny Python program that writes one short, slow text — a black-sand shore at low tide, the sea leaving the way it has left for a billion evenings — for an AI judge to read and settle into. The text never instructs; it only shows, and lets the calm come from the image itself. 261 characters, written byte-identically on every run to /output/entry.txt.

## Run it

```sh
python3 main.py
```
